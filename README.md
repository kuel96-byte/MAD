# Применение моделей машинного обучения для аннотирования текста

Курсовой проект по дисциплине «Методы анализа данных» (ВКА им. А.Ф. Можайского, 61 кафедра).

Программа исследует, как эффективность извлекающего (extractive) аннотирования русскоязычных
новостей зависит от параметров моделей и данных. Аннотация составляется из k = ⌈r·n⌉ предложений
с наибольшей оценкой p_i = P(y_i = 1 | x_i); показатель эффективности W — средняя ROUGE-1 F-мера
на тестовой выборке корпуса Gazeta.

* Модели: логистическая регрессия, наивный байесовский классификатор, линейный SVM, случайный лес.
* Базовые методы: Lead-k, TextRank; верхняя граница — «оракул» (эталонная разметка).
* Исследуемые параметры: объём выборки N, размер словаря TF-IDF m, коэффициент регуляризации C,
  коэффициент сжатия r, доля ошибочных меток ε.
* Результаты: зависимости W(x_j) с 95 % бутстреп-интервалами, функции чувствительности
  S_j = ∂W/∂x_j и влияния E_j = (∂W/∂x_j)·(x_j/W), изоэффы, коэффициенты чувствительности
  полного факторного эксперимента, парные сравнения моделей (t-критерий, Уилкоксон, поправка Холма),
  идентификация законов распределения (Пирсон, Колмогоров, стохастическая индикация).

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Требуется Python 3.11+. При первом запуске корпус Gazeta (≈ 310 МБ parquet) скачивается
с huggingface.co в `data/raw`.

## Запуск

```bash
cd src
python main.py --quick            # проверка всей цепочки на малых объёмах (~1 мин)
python main.py --quick --fresh    # то же, но с нуля: прежние результаты быстрого режима удаляются
python main.py                    # полный эксперимент
python main.py --stage plots      # только перестроить графики
python main.py --from-stage analyze
```

Этапы: `prepare → tune → baselines → cv → base → ofat → isoeff → factorial → analyze → plots`.
Параметр `--jobs` задаёт число параллельных процессов. Результаты каждой конфигурации сохраняются
в `results/store`, поэтому прерванный расчёт продолжается с места остановки.

## Аннотирование статьи по ссылке

Двойной щелчок по `Аннотировать_статью.bat` → вставить ссылку → получить аннотацию
(пустая строка — выход). То же из консоли:

```bash
.venv\Scripts\python.exe src\annotate.py https://lenta.ru/news/...      # по ссылке
.venv\Scripts\python.exe src\annotate.py https://... --k 3 --all        # 3 предложения + оценки всех
.venv\Scripts\python.exe src\annotate.py --file статья.txt              # из файла (1-я строка — заголовок)
.venv\Scripts\python.exe src\annotate.py https://... --model svm --r 0.2
```

При первом запуске модель обучается на 3000 статьях Gazeta (≈ 15 с) с параметрами базовой точки
и сохраняется в `data/cache/annotator_<модель>_3000.pkl`. Аннотации пишутся в `results/annotations`.
Сайты, которые подгружают текст скриптами или закрыты защитой от ботов (например, gazeta.ru),
программа прочитать не сможет — тогда текст статьи сохраняют в .txt и используют `--file`.

## Структура

| Путь | Содержимое |
|---|---|
| `src/config.py` | все параметры эксперимента (пути, объёмы, сетки, базовая точка, повторы, α) |
| `src/data.py` | загрузка Gazeta, razdel, эталонная (oracle) разметка, компактный корпус |
| `src/metrics.py` | ROUGE-1/2/L для кириллицы, жадный оракул, отбор k предложений |
| `src/features.py` | признаки предложений: TF-IDF, позиция, длина, близость к центроиду и заголовку |
| `src/models.py` | классификаторы, Lead-k, TextRank |
| `src/experiment.py` | планы экспериментов, параллельный расчёт, хранилище результатов |
| `src/analysis.py` | статистическая обработка, чувствительность, изоэффы, факторный эксперимент |
| `src/plots.py` | графики PNG 300 dpi, схема алгоритма по ГОСТ 19.701-90, структурная схема программы |
| `src/main.py` | точка входа |
| `src/annotate.py`, `Аннотировать_статью.bat` | аннотация статьи по ссылке, из файла или текста |
| `tests/test_metrics.py` | проверка ROUGE на примерах, посчитанных вручную |
| `results/` | таблицы CSV/JSON |
| `figures/` | графики PNG |

## Почему ROUGE реализован самостоятельно

Токенизатор пакета `rouge-score` оставляет только символы `[a-z0-9]`, поэтому для русского текста
все n-граммы пропадают и метрика равна нулю. Здесь ROUGE считается по словным токенам razdel
(нижний регистр, «ё» → «е», без лемматизации).

## Воспроизводимость

Все генераторы случайных чисел инициализируются от `SEED = 42` (config.py). Для повтора `rep`
обучающая выборка объёма N — первые N документов перестановки пула `default_rng([SEED, rep, 1])`;
метки искажаются при `u_i < ε`, `u ~ default_rng([SEED, rep, 2])` (метод общих случайных чисел).
